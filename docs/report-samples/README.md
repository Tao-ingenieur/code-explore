# 分析报告样例

四个项目的 PDF 分析成果，便于预览离线报告的交付形式。报告绑定各自的源码快照与内容版本，不包含完整源码资料包。

- `01-agent`：[《Agent源码深度解读》](<Agent源码深度解读.pdf>)
- `02-opencode`：[《OpenCode源码深度解读》](<OpenCode源码深度解读.pdf>)
- `03-comparison`：[《某Agent和OpenCode架构对比》](<某Agent和OpenCode架构对比.pdf>)
- `04-niugu-test`：[《股票分析Skill解读》](<股票分析Skill解读.pdf>)

第 4 份报告由资料包内容版本 2.0.1 生成，共 37 页；报告描述源码与工作流及离线合成样例，不提供投资结论。完整阅读和定位源码仍需对应资料包。

[单项目提示词](../agent-prompt.md)和[对比提示词](../comparison-prompt.md)默认要求生成同源 PDF/TeX；不需要时可明确将参数改为“不要求”。
