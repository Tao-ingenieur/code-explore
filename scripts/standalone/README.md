# Code Explore / 源码导航：运行包

需要 Node.js 20+，无需 repo、node_modules 或 npm 安装。

在本目录打开终端：

```powershell
node serve.mjs --port 4173
```

访问 http://127.0.0.1:4173/ ，按 Ctrl+C 停止。
也可从任意位置运行 `node <dist目录的路径>/serve.mjs`；路径以脚本所在位置为基准。

- `serve.mjs`：独立本地服务器，仅监听 127.0.0.1。
- `package-checks.mjs`：只读资料包检查，需与 serve.mjs 一同保留。
- `build/`：已编译网站与项目目录索引。
- `output/`：已有分析资料包，直接读取，无需复制。
- `input/`：待分析源码 ZIP，网站不自动分析。

首页主要入口“刷新本地资料包”直接刷新服务中的 output 项目，不弹目录授权。“打开其他目录（需授权）”用于 output 之外的目录，使用浏览器目录授权，直接读取选中目录的原文件。需要支持 File System Access API 的 Chrome/Edge；浏览器可能提示“查看和复制”，这是浏览器授权文案，不代表网站会复制整份资料。
浏览器只保存目录句柄与项目元数据；权限失效时点击“重新授权目录”。此前通过 Windows 系统窗口接入的项目，也需重新授权并选择同一资料包目录。
推荐将标准资料包放在 `output/<项目ID>/`，其中包含 `project.json`。本地服务实时扫描这些资料包，刷新网页即可更新列表；卡片标记为“服务读取”，不需要浏览器目录授权。同 ID 的旧目录登记会自动让位于服务入口，阅读位置继续保留。其他位置的目录仍可手动授权接入。
本地服务优先读取 output 的现有项目，不使用 build 中同 ID 的旧副本；移除项目只隐藏浏览器中的记录，不删除磁盘文件。单项目格式说明和完整提示词在网页的“资料包格式说明”入口。
服务读取同样检查源码、符号、搜索、报告及身份/版本信息，告警显示在项目卡片的可展开清单中；刷新时重新检查，不修改资料包。

整体移动此目录后仍可运行。
前端程序需要更新时，在源码仓库执行 `npm run build:app`，再使用更新后的运行包。新增或修改 output 资料包只需刷新网页；更新 serve.mjs 后需重启本地服务。
仅使用普通静态服务器托管 build 时，需先生成含完整资料包的静态部署版本；本启动器支持直接读取旁边的 output。

提示词文件随网站构建自动更新：`build/docs/agent-prompt.md` 和 `build/docs/comparison-prompt.md`。网页展示和复制的正文随前端重新构建更新，下载入口读取上述文件；修改 repo 中的提示词后执行 `npm run build:app`，再刷新网页。单独修改源码文档不会自动更新已有运行包。报告默认要求 PDF/TeX，可明确改为“不要求”；报告生成器与版式可自行选择，不适用的领域模板内容应删除。
