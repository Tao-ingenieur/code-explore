# Code Explore / 源码导航：运行包

需要 Node.js 20+，无需 repo、node_modules 或 npm 安装。

在本目录打开终端：

```powershell
node serve.mjs --port 4173
```

访问 http://127.0.0.1:4173/ ，按 Ctrl+C 停止。
也可从任意位置运行 `node <dist目录的路径>/serve.mjs`；路径以脚本所在位置为基准。

- `serve.mjs`：独立本地服务器，仅监听 127.0.0.1。
- `build/`：已编译网站与项目目录索引。
- `output/`：已有分析资料包，直接读取，无需复制。
- `input/`：待分析源码 ZIP，网站不自动分析。

“打开资料包目录”使用浏览器目录授权，直接读取选中目录的原文件。需要支持 File System Access API 的 Chrome/Edge；浏览器可能提示“查看和复制”，这是浏览器授权文案，不代表网站会复制整份资料。
浏览器只保存目录句柄与项目元数据；权限失效时点击“重新授权目录”。此前通过 Windows 系统窗口接入的项目，也需重新授权并选择同一资料包目录。
output 中由目录索引列出的项目仍可直接读取。单项目格式说明和完整提示词在网页的“资料包格式说明”入口。

整体移动此目录后仍可运行。
前端及目录索引需要更新时，在源码仓库执行 `npm run build:app`，再使用更新后的运行包。
仅使用普通静态服务器托管 build 时，需先生成含完整资料包的静态部署版本；本启动器支持直接读取旁边的 output。
